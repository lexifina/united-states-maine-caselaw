# State v. Handy

## Majority (By the Court)

By the Court
Several questions of interest have been raised in this case, but it will not be necessary to consider all of them. The order is set forth in the indictment for the sum of forty-eight dollars. But upon inspection of the instrument alleged to be forged, it appears that there is the further sum of one, dollar due. It is then an order for the sum of forty-nine dollars, and the instrument not having been truly set forth, the exceptions are sustained, and the verdict set aside.
